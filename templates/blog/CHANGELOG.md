# Changelog — @templates/blog

All notable changes to this template will be documented in this file.

## [1.0.0] — 2026-02-24

### Added
- Initial release of the blog content management template
- `category` object — blog categories with slug and parent support
- `post` object — blog posts with rich text, status workflow, and author
- `comment` object — reader comments with moderation workflow
- Plugin definition with content management navigation
- Standalone `objectstack.config.ts` for local development
