# Changelog — @templates/todo

All notable changes to this template will be documented in this file.

## [1.0.0] — 2026-02-24

### Added
- Initial release of the todo task management template
- `todo_list` object — named task lists with title, color, and owner
- `todo_item` object — tasks with priority, status, due date, and list lookup
- Plugin definition with navigation groups
- Standalone `objectstack.config.ts` for local development
